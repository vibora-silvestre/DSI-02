# Agenda 03
Criação de um formulário de descontos
Sobre o que foi solicitado na atividade, a maior parte dos erros lógicos estavam concentrados nos valores incorretos aplicados nos descontos, além de ter sido necessário criar uma nova variável chamada valorfinal para subtração do valor do pagamento ao desconto, podendo assim, ser apresentado o valor final pago pelo cliente na mensagem.
Além disso, tentei utilizar o number_format dentro das mensagens, porém ocasionou erros no código, dessa forma, alterei minha abordagem mantendo os números como números durante todo o calculo e posteriormente nos números finais destrinchei os valores de pagamento, desconto e valor final formatos em reais utilizando o number_format.
